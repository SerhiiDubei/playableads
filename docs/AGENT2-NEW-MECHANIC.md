# Агент 2 — створення нової механіки (locked)

Окрема ідея від Агента 1 (серфінг готових шаблонів). Агент 2 = **експерт зі створення
маленьких ігор**, що з нуля збирає міні game-design doc, з якого генерується `game.ts`.

Постава: помічник-експерт, не допитувач. Веде через референс.

## Кінцевий бриф (предмет збору)

### 🔴 Етап 0 — Референс (якір усього)
- **`ref`** — 1+ конкретна гра/механіка-орієнтир (+лінк).
  - Юзер дав → парсимо.
  - Юзер не може → агент пропонує **реальні** ігри-архетипи (з лінком) → «оце?».
  - Засторога: назви/лінки лише зі звіреного списку архетипів, не фантазія LLM.

### 🔴 Без цього не можна
1. **`coreAction`** — що палець робить: tap / swipe / drag / aim (одне дієслово).
2. **`objects`** — хто на екрані: гравець, цілі, перешкоди, збиранки.
3. **`goal`** — ціль + умова виграшу.
4. **`tension`** — напруга / fail: таймер / життя / промах.
5. **`ahaMoment`** — той ОДИН смаковий біт, що реклама продає.

### 🟠 Інакше — low-level продакшн
6. **`loop`** — тривалість (~15-30с), к-сть бітів, ріст складності.
7. **`ctaHook`** — момент, що рве на install.
8. **`winLose` + `feedback`** — стани + juice (партикли, шейк, звук).

## Потік
1. «Потрібен playable» → агент: «на що схоже?»
2. Нема відповіді → 2-3 реальні гри-референси з лінками.
3. Тиць → з референсу витягуємо coreAction/objects/goal/loop одним прикладом.
4. Добиваємо tension, aha, CTA картками.
5. Показ зібраного GDD → ✓ → scaffold у labs/.

Ключ: референс = вхід, з якого розкручується решта. Бриф описує **правила, не картинки**.
