# PIPELINE — як ми будуємо плейбл (ЄДИНЕ джерело)

> Це **одне місце правди** про наш процес. Усе інше (`../CLAUDE.md`, `repo/CLAUDE.md`)
> лише посилається сюди. Якщо процес міняється — міняємо ТУТ, більше ніде.
> Простою мовою, без жаргону.

## Головна ідея

Будуємо **фабрику плейблів**, не окремі плейбли. Кожен плейбл їде **конвеєром** із
8 станцій. На кожній станції хтось (роль) бере «папірець» (готовий результат
попереднього кроку), робить свою частину й віддає новий папірець далі. Між станціями —
**гейт** (перевірка), без якого далі не йдемо.

**Видимий конвеєр (наше правило):** на кожен плейбл є тека `labs/<id>/_pipeline/` з
документом на кожну станцію. Я заповнюю станцію → показую папірець → ти ставиш ✅ →
іду далі. **Без ✅ далі не йду.** Стан видно на дошці.

## Дві гілки + ДВА UI-набори

Після ЗАДУМУ (станція 2) обираємо ТИП. Кроки 1–4 і 7–8 однакові; різні лише 5 і 6.

| | **A — меню-демо** | **B — гра** (зараз у фокусі) |
|---|---|---|
| Що це | статичні екрани (меню/ендкард/tutorial) | справжня гра (свайпи, таймери, фізика) |
| Перший файл | `styles/<id>.brief.json` | `labs/<id>/{game.ts, manifest.json, assets/}` + `styles/<id>.json` |
| Збірка | `npm run forge -- <id>` | `npx tsx src/assetgen/build-lab.ts <id>` → `test/<id>/` |
| **UI-набір** | **`kit.ts`** (9-slice з AI-асетів + `layouts/`) | **`kit/ui.ts`** — game-UI (DOM/CSS overlay) |
| Перевірка | `npm run check:layouts` (R1–R6) + `npm run visual` | `node tools/qa-lab.mjs <id>` + критик краси |
| Приклад | fruit-bonanza menu | **avoid-the-accident** |

**Два набори для двох гілок.** Кожен — єдине джерело UI для СВОЄЇ гілки:
- Гілка A: `src/assetgen/kit/kit.ts` (+ `layout.ts` зони + `layouts/`).
- Гілка B: `src/assetgen/kit/ui.ts` (game-UI: overlay, `buildEndcard`, токени; див. `GAME-UI.md`).

`ui.ts` — **офіційний набір гілки B, не фріланс.** Малювати UI примітивами Pixi або
заводити третій паралельний модуль — заборонено (це і є «фріланс», див. `ANTIPATTERNS.md`).

## Перевірки (гейти) перед «готово»

**Спільне (обидві гілки):** `npm run typecheck` чистий · вага ≤2 МБ · весь endcard
клікабельний → `onCTAClick` · BUILD-LOG оновлено.

**Гілка B (гра) — одна команда:** `node tools/verify-lab.mjs <id>` ганяє typecheck →
build-lab → qa-lab (0 помилок на 375×667 і 393×851) → бюджет + **критик краси**
(огляд скрінів: не лише «нема помилок», а «виглядає добре»). Падає голосно.

**Гілка A (меню):** `npm run check:layouts -- <id>` (R1–R6) + `npm run visual`.

## Як почати новий плейбл

```bash
node tools/new-lab.mjs <id>     # створює labs/<id>/ підключеним до game-UI + _pipeline/ шаблони + STATUS.md
```
Далі — станція за станцією, кожна дає папірець у `_pipeline/`, ти ✅, я далі. Стан — на
`labs/BOARD.md`.

## Дошка
