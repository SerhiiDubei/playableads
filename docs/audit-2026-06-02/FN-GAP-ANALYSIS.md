## Головний висновок
**Це продакшн-розрив, не дизайнерський.** Схема refgames вже містить усі потрібні поля
(`animations`, `assets.sprites/vfx/sfx`, `ahaMoments` з комбо) — вона «знала». Розрив виник,
бо тест навмисно йшов **code-only + без звуку**, щоб ізолювати якість логіки.

→ Схема не лише достатня для логіки — вона тримає **roadmap закриття розривів**.

## Що це означає для наступних кроків
1. **Генерація має ВИКОРИСТАТИ `animations`/`assets`/`sfx`**, а не ігнорувати (зараз контракт code-only).
2. **Аудіо-система** — додати в контракт `game.ts` (підключення sfx із `cfg.assets`).
3. **AI-ассети** — спрайти фруктів (цілий + 2 половинки), сік, бомба, фон-додзьо.
4. **Точність анімації** — справжній split по куту + фізика половинок + слід-лезо + банер комбо.
5. **Стиль/тема** — UI з стиль-брифа (дерево/додзьо), не generic.

## Що НЕ потрібно міняти
- Схему (достатня).
- Логіку циклу (дія→score→win→CTA працює, перевірено наскрізно).
- Прогрес-бар до цілі — це валідний ad-ism (реальна гра endless/timed, але для playable ок).
