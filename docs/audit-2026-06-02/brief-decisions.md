## Наскрізні рішення (повторювались поза окремими Q)

1. **Два режими:** `dev` (зміни коду, довчання, порушення правил) vs `user`/designer (без коду, лише інпут+правки в межах конструктора).
2. **Human-in-the-loop за майлстоунами** — кожен етап підтверджується; можна перебити будь-коли (Q10) + overpush-кнопка (Q30).
3. **Інтерактивний viewport/мокап (грейбокс)** — агент показує що додав, об'єкти рухомі/масштабовані (S1, Q14, Q29). Велика наскрізна вимога.
4. **Prediction вартості перед генерацією** (Q32) + **збереження невдач для debug** (Q35).
5. **Версіонування + нетригерний відкат** усього (Q25).
6. **«Warn, але роби»** для м'яких правил; критики (style/semantic) — **відкладені**, щоб не роздувати pipeline (Q20, Q43).
7. **Референс-картинки обов'язкові** для якості (Q17) + **дозаповнення відсутнього контексту** агентом (Q08).
