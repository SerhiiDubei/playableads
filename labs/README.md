# labs/ — чернетки ігор (draft games)

**Тут живе кожна гра за замовчуванням.** Це майстерня: експерименти, прототипи, ігри в роботі.

## Принцип (рішення 2026-06-02)
- Нова гра/механіка/експеримент → **сюди**, у `labs/<назва>/`.
- «**Шаблоном**» (`/templates/`) гра стає ТІЛЬКИ: (1) коли є стандарт шаблону
  ([`docs/TEMPLATE-STANDARD.md`](../docs/TEMPLATE-STANDARD.md)) **і** (2) за прямим запитом на промоцію.
- Поки стандарту нема → **0 ігор є шаблонами**, усе живе тут.

```
нова гра → labs/<гра>/ → (стандарт існує + явний запит) → templates/<гра>/
           (чернетка)                                       (промоутовано)
```

## Структура lab-гри (пропозиція, не жорстко)
```
labs/<гра>/
  README.md       # що це, статус, що працює/не працює
  game.ts         # код (або build-*.ts поки)
  assets/         # ассети (якщо є)
  notes.md        # чернеткові нотатки (опц.)
```

## Що сюди переїде (задача S-02, ПІСЛЯ T-01)
Поки що НЕ перенесено — лише підготовлено місце. Кандидати на переїзд:
- `templates/tap-the-coin`, `templates/plug-in-socket`, `templates/mad-mage-tower` (зараз помилково в `templates/`)
- `src/assetgen/build-game.ts`, `build-connect.ts`, `build-experiments.ts`, `build-recipes.ts`

> Не плутати з `src/assetgen/labs/` — то reference-дані для asset-gen (інший шар), не ігри.
