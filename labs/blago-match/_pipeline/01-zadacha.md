# ЗАДАЧА (бриф) — blago-match

- **Продукт / бренд:** Будівельна компанія **«Благо»** — забудовник житла в Івано-Франківську (новобудови / квартири).
- **Сегмент (хто гравець):** Франківчани (основа) + приїжджі, хто розглядає купівлю житла в ІФ. Дорослі 25–45, мобільний трафік.
- **Кінцева дія (CTA):** Отримати **знижку до Дня Незалежності** (лід / промокод) — кнопка ендкарду веде на заявку, не на стор.
- **Дедлайн:** прив'язка до **28 серпня (День Незалежності)** — кампанія має жити до цієї дати.

### Обмеження / контракт
- **Мова:** українська (весь текст у грі та ендкарді — UA).
- **Вага:** ≤ 2 МБ single-file (Meta/playable budget).
- **Тон:** святковий (День Незалежності) + довіра до забудовника; акуратно з держ-символікою (без political risk).

### Чому Match під цей бриф
Механіка **match** дає природний прогрес «зібрав N → виграш → нагорода». Нагорода = **знижка**, що
прямо лягає на CTA. Плитки = елементи бренду «Благо» (ключі, цеглинки, дім, % знижки) — агностичний
кістяк, під бренд міняються лише асети, не код.
